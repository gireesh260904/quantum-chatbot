# Quantum Chatbot

## Overview

Quantum Chatbot is an AI-powered chatbot built using Flask, Qiskit, Sentence Transformers, and FAISS. The application enables users to ask questions related to quantum computing and receive intelligent responses through natural language processing and semantic search techniques.

## Features

* Interactive chatbot interface
* Natural language query processing
* Semantic search using Sentence Transformers
* Fast similarity search with FAISS
* Quantum computing concepts powered by Qiskit
* Web-based user interface built with Flask
* Easy deployment and scalability

## Technologies Used

## Installation

### Clone the Repository

```bash
git clone https://github.com/gireesh260904/quantum-chatbot.git
cd quantum-chatbot
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

## Running the Application

Start the Flask server:

```bash
python app.py
```

Open your browser and navigate to:

```text
http://127.0.0.1:5000
```
